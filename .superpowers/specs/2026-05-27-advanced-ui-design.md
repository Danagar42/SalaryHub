# Специфікація дизайну: Advanced UI/UX SalaryHub (v2)

Цей документ описує архітектурну та технічну специфікацію для інтеграції преміального інтерактивного дизайну, Framer Motion мікро-анімацій та Glassmorphism ефектів у версію пісочниці `v2/index.html`.

---

## 1. Скляні інтерактивні картки статистики (Glow & Float)

### Мета:
Перетворити статичні картки показників на дашборді на чутливі скляні віджети, які левітують та підсвічуються кольоровим неоном при наведенні.

### Специфікація реалізації:
- **Елемент тла**: `backdrop-blur-lg bg-white/40 dark:bg-slate-800/40 border border-white/20 dark:border-slate-700/30 shadow-xl`
- **Анімація hover (картка)**: 
  - `whileHover={{ y: -6, scale: 1.01 }}`
  - `transition={{ type: "spring", stiffness: 300, damping: 20 }}`
  - **Тінь ( сяйво )**: При наведенні створюється `boxShadow` з розмиттям 30px відповідного кольору:
    - *Середній дохід*: смарагдове сяйво (`rgba(16, 185, 129, 0.15)`)
    - *Курс USD*: синє сяйво (`rgba(59, 130, 246, 0.15)`)
- **Анімація hover (іконка)**:
  - Коли картка наведена, її іконка робить плавне вертикальне коливання:
    - `animate={{ y: [0, -4, 0] }}`
    - `transition={{ repeat: Infinity, duration: 1.8, ease: "easeInOut" }}`

## 2. Безшовне ковзання меню та кінематична зміна сторінок

### Мета:
Зробити навігацію схожою на нативний додаток з плавним перетіканням елементів.

### Специфікація реалізації:
- **Перетікання фону активного таба**:
  - Використання Framer Motion `<motion.div layoutId="activeNavBubble" />` для активної кнопки меню.
  - При зміні стану `activeTab` фон кнопки переміститься до нового пункту меню за допомогою інтерполяції координат Shared Layout з фізикою пружини:
    `transition={{ type: "spring", stiffness: 380, damping: 30 }}`
- **Кінематичні сторінки (Page Transitions)**:
  - Заміна звичайного `AnimatePresence` у блоці `<main>` на 3D просторову зміну:
    `const pageVariants = { initial: { opacity: 0, x: 15, filter: "blur(4px)" }, animate: { opacity: 1, x: 0, filter: "blur(0px)", transition: { type: "spring", stiffness: 300, damping: 25 } }, exit: { opacity: 0, x: -15, filter: "blur(4px)", transition: { duration: 0.15 } } };`

## 3. Живі мікро-анімації для форм та таблиць

### Мета:
Додати тактильний відгук на дії користувача (фокус, наведення на списки, збереження).

### Специфікація реалізації:
- **Підсвічування рядків таблиці**:
  - Рядки `motion.tr` при hover отримують плавний скляний фон:
    `whileHover={{ backgroundColor: "rgba(59, 130, 246, 0.05)" }}`
- **Плаваючі кнопки дій**:
  - Кнопки дій у таблиці з'являються плавно і зміщуються на місце тільки при наведенні на конкретний рядок за допомогою Framer Motion.
- **Висвітлення конфеті з точки кліку**:
  - Використання координат кліку `event` при виклику конфеті для перерахунку `origin: { x: event.clientX / window.innerWidth, y: event.clientY / window.innerHeight }`.
